# Retail Store and Distribution Software

The Retail Store and Distribution Software includes a comprehensive set of reports and features such as:
**Top Customer Report, Top Salesman Report, Brands Report, Section Report, Company-wise Report, Store-wise Report, SKU-wise Report, Return Report, and Bank Collection.**

It also allows direct stock management — stock from purchase is automatically updated and reduced when returns or purchase orders occur.

---

## 🧩 Main Features

- Point of Sale and Offer Discounts  
- Credit Sales  
- Top Customer, Top Salesman, Brands, Company-wise, and Store Reports  
- Purchase Order Management  
- View and Manage Invoices  
- Offer Discounts  
- Stationery and Super Mart Support  
- Barcode Reader Integration  
- Out-of-Stock Alert Notifications  
- Detailed Stock Management  
- Add Banks, Cheques, Deposits, and Suppliers  
- Upload Items Through CSV  
- Financial Accounting Module  
- 100% Responsive for All Devices  
- Stock, Sales, and Return Reports  
- And much more...

---

### 💻 Technology Stack
- PHP (CodeIgniter Framework)  
- MySQL Database  
- HTML, CSS, JavaScript, jQuery  
- Bootstrap Frontend Framework  

---

### ⚙️ Installation
1. Clone or download the project.  
2. Import the provided SQL file into your MySQL database.  
3. Configure your database settings in `/application/config/database.php`.  
4. Update the base URL in `/application/config/config.php`.  
5. Run the project on your local or online server.
